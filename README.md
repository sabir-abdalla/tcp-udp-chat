TCP & UDP Chat Application

A simple Python chat application demonstrating both TCP and UDP socket programming.

Features
- **TCP Chat** (server.py & client.py): Reliable, connection-oriented chat with multi-threading.
- **UDP Chat** (udp_server.py & udp_client.py): Fast, connectionless chat using datagrams.

How to Run
1. Start the server: python server.py (or python udp_server.py)
2. Start the client in a new terminal: python client.py (or python udp_client.py)
3. Choose a nickname and start chatting!
